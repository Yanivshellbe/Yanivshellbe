# Yaniv Money Machine

מערכת מסחר אלגוריתמית עבור חשבון Alpaca Paper (100K$) עם יעד להגיע ל-100K+ במהירות ובבטחה ככל האפשר.

## סטטוס נוכחי

- [x] **שלב 0 — תשתית ויזואלית**: דשבורד בסיסי + מבנה ריפו
- [ ] **שלב 1 — קליטת רעיונות**: ממתין לרשימת הרעיונות מהמשתמש
- [ ] **שלב 2 — תקיפה והגנה**: ניתוח כשלים בכל רעיון + תיקונים
- [ ] **שלב 3 — חיבור Alpaca**: API keys, account info, market data
- [ ] **שלב 4 — מנוע אסטרטגיות**: רישום, ניקוד שבועי, בחירה
- [ ] **שלב 5 — Backtesting**: הרצה מהדשבורד
- [ ] **שלב 6 — Dream Scan לילי**: סריקה אוטומטית + מסקנות
- [ ] **שלב 7 — Live Execution**: דמה תחילה, גישור לכסף אמיתי בהמשך

## פתיחת הדשבורד

פתח את `dashboard/index.html` בדפדפן. עדכון אוטומטי לכל הסטטוסים נשמר ב-`dashboard/state.json`.

## מבנה ספריות

```
.
├── dashboard/          # ויזואליזציה (HTML/CSS/JS ללא תלויות)
├── backend/            # מנוע מסחר (יבנה אחרי גיבוש רעיונות)
├── strategies/         # אסטרטגיות בודדות
├── config/             # קבצי קונפיג
└── docs/               # ארכיטקטורה והחלטות
```

## הגדרות יסוד

- **חשבון**: Alpaca Paper, יתרה התחלתית 100,000$
- **סטטוס מסחר**: PDT (Pattern Day Trader) — DTBP זמין
- **כיוונים**: לונג + שורט בו זמנית
- **מינוף**: בשימוש היכן שמותר ומחושב

המערכת **לא תפעל בלייב** עד אישור מפורש של המשתמש.
